## 1. Contexto de Negócio e Metodologia
O projeto consiste em um painel inteligente voltado à gestão pública (GovTech) para diagnosticar e resolver os problemas de conectividade nas escolas do estado de Mato Grosso do Sul (MS). 

Como ponto de partida, utilizamos o Ranking Connected Smart Cities 2025, que avalia todas as cidades brasileiras por meio de média simples e fontes secundárias. No entanto, o indicador de "Porcentagem de Escolas com Banda Larga" do ranking (proveniente do Censo Escolar/INEP) é meramente declaratório e estático. 

Nossa solução inovadora propõe uma avaliação dinâmica em 3 fases:
- **Fase 1 (Mapeamento):** Levantamento espacial de todas as escolas (urbanas e rurais) e dados de governança pública dos 79 municípios de MS.
- **Fase 2 (Comparativo Técnico):** Cruzamento do número de matrículas (INEP) com a velocidade real medida nas escolas pelo SIMET (NIC.br) para calcular o índice de banda larga por aluno no turno de pico (Meta ENEC: 1 Mbps por aluno).
- **Fase 3 (Engenharia de Soluções):** Mapeamento automático de provedores regionais e análise de custo-benefício para alternativas tecnológicas (como satélites de órbita baixa - LEO) onde há gargalo físico de fibra óptica.

3. Arquitetura do Banco de Dados (SQLite)
Escreva o arquivo database.py para criar o arquivo de banco de dados govtech_ms.db e rodar o script SQL DDL de criação de tabelas abaixo:
import sqlite3

def criar_banco_dados():
    conexao = sqlite3.connect("govtech_ms.db")
    cursor = conexao.cursor()
    
    # 1. Tabela de Municípios (Dados de Governança do Smart Cities)
    cursor.execute("""
    CREATE TABLE IF NOT EXISTS municipios (
        co_municipio INTEGER PRIMARY KEY,
        no_municipio TEXT NOT NULL,
        nota_transparencia_ebt REAL, -- Escala Brasil Transparente (CGU)
        investimento_per_capita_educacao REAL, -- Siconfi (Tesouro Nacional)
        conselho_educacao_ativo INTEGER DEFAULT 1, -- MUNIC (IBGE)
        populacao_estimada INTEGER
    );
    """)
    
    # 2. Tabela de Escolas (Microdados INEP Censo Escolar)
    cursor.execute("""
    CREATE TABLE IF NOT EXISTS escolas (
        co_entidade INTEGER PRIMARY KEY,
        no_entidade TEXT NOT NULL,
        co_municipio INTEGER,
        tp_localizacao TEXT CHECK(tp_localizacao IN ('Urbana', 'Rural')),
        in_internet INTEGER DEFAULT 0,
        in_banda_larga INTEGER DEFAULT 0,
        qt_matriculas INTEGER DEFAULT 0,
        latitude REAL,
        longitude REAL,
        FOREIGN KEY (co_municipio) REFERENCES municipios(co_municipio)
    );
    """)
    
    # 3. Tabela de Medições Reais (SIMET / NIC.br)
    cursor.execute("""
    CREATE TABLE IF NOT EXISTS medicoes_simet (
        co_medicao INTEGER PRIMARY KEY AUTOINCREMENT,
        co_entidade INTEGER,
        velocidade_download_real REAL, -- em Mbps
        velocidade_upload_real REAL, -- em Mbps
        latencia REAL, -- em ms
        perda_pacotes REAL, -- em %
        data_medicao TEXT,
        FOREIGN KEY (co_entidade) REFERENCES escolas(co_entidade)
    );
    """)
    
    # 4. Tabela de Alternativas de Mercado (Provedores e Tecnologias)
    cursor.execute("""
    CREATE TABLE IF NOT EXISTS alternativas_mercado (
        co_provedor INTEGER PRIMARY KEY AUTOINCREMENT,
        tecnologia TEXT CHECK(tecnologia IN ('Fibra Óptica', 'Satélite LEO', 'Rádio WISP')),
        no_provedor TEXT NOT NULL,
        velocidade_oferta REAL, -- em Mbps
        custo_mensal REAL, -- em R$
        viabilidade_rural INTEGER DEFAULT 0
    );
    """)
    
    conexao.commit()
    conexao.close()
    print("Banco de dados 'govtech_ms.db' criado e estruturado com sucesso!")

if __name__ == "__main__":
    criar_banco_dados()

5. Interface Gráfica Interativa (app.py)
Escreva o arquivo app.py. A interface Streamlit deve ser impecável, profissional e estruturada nas 3 fases planejadas. Use plotly para criar gráficos modernos de comparação e folium para os mapas geográficos.
Implemente os seguintes recursos em app.py:
Menu Lateral: Identificação da UFMS, a disciplina, os nomes de vocês quatro como autores e um seletor de "Filtro Geral por Município" de MS (com a opção "Todos os Municípios").
Guia 1: Fase 1 — Mapeamento de Infraestrutura
KPIs: Quantidade de escolas municipais mapeadas, % de conectividade geral.
Visualização: Um mapa de Mato Grosso do Sul (usando folium) plotando marcadores das escolas de MS (Dica: Use marcadores Azuis para Urbanas e Laranja para Rurais, e mude o ícone para "remover" caso estejam sem internet).
Análise de Discrepância: Gráfico de barras comparativo mostrando a taxa de conectividade de Escolas Rurais vs. Escolas Urbanas agrupadas por município.
Guia 2: Fase 2 — Comparativo Técnico de Banda por Aluno
A Lógica Algorítmica: Calcule a banda por aluno no turno de pico (estimando o turno de pico em 40% das matrículas totais).
Fórmula: (Velocidade SIMET em kbps) / (Matrículas Totais * 0.40).
Classificação:
Adequada: >= 1000 kbps/aluno (Cor: Verde)
Parcial: 100 a 999 kbps/aluno (Cor: Amarela)
Insuficiente: < 100 kbps/aluno (Cor: Vermelha)
Visualizações: Gráfico de pizza com a distribuição da qualidade real da conexão estadual e uma tabela interativa das escolas filtradas de MS.
Guia 3: Fase 3 — Engenharia de Soluções de Mercado & SWOT
Algoritmo do IPI (Índice de Prioridade de Intervenção): Calcula a prioridade (0 a 100) para cada escola vulnerável usando a fórmula: IPI = (0.50 * (1 - Status_Internet_Banda_Larga)) + (0.30 * (Peso_Rural)) + (0.20 * (Matrículas / Maior_Matrícula_MS)) * 100
Recomendador Inteligente: Se a escola for rural e sua velocidade medida for < 10 Mbps, sugira a contratação de tecnologia de Satélite LEO (Starlink) ou Provedor Local de Rádio de forma dinâmica. Mostre o custo mensal estimado e o ganho em Mbps.
Apresentação SWOT: Aba interna exibindo a Matriz SWOT de forma limpa e acadêmica.
